# newcxx

Small tool to setup a new cmake project for C++ just the way I like it, so I never have to remember CMake again. Written in Rust, ironically.

It creates a new directory + git repo for the project, adds a `src/include/` file structure, two `CMakeLists.txt` files and a `main.cpp` file to get started.

Run `./newcxx -help` for use info.
